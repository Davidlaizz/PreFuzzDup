这些是客户端准备阶段测量，不包含 Git、人工等待或服务端检索。通信仅按 RTT 1 ms、1 Gbit/s 估算，当前没有实测网络时间。历史 2,259 份参考密文只有整体准备耗时，不倒推加密阶段数据。

本机集成验收：18 次真实密文签名/验签/解密/确认通过，18 次重放拒绝；全量 91,800 行检索结果与独立候选真值一致。这些不作为 4110 正式性能结果。
